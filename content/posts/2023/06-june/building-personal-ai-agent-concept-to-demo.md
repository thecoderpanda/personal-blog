We are going to build a personal productivity agent in Python from scratch. No heavy, bloated agent frameworks. No LangChain wrappers. No AutoGPT magic. Just raw Python, the OpenAI API, and a clean implementation of the **ReAct (Reason + Act)** loop.

By the end of this tutorial, you will have an agent running in your local terminal that can read your workspace files, search local directories, and execute mathematical calculations, all while managing its own task execution queue.

## Step 2: Defining our Execution Tools

Let’s write the tools our agent can use. These are basic Python functions that interact with our local operating system or perform calculations. We will define three core tools:
1.  `list_directory`: Lists all files in the current workspace.
2.  `read_workspace_file`: Reads raw text content from a file.
3.  `calculate`: Safely executes mathematical equations.

Create a file named `tools.py` and write the following functions:

```python
import os

def list_directory(directory_path="."):
    try:
        files = os.listdir(directory_path)
        return "\n".join(files)
    except Exception as e:
        return f"Error listing directory: {str(e)}"

def read_workspace_file(file_path):
    try:
        with open(file_path, "r", encoding="utf-8") as f:
            return f.read()
    except Exception as e:
        return f"Error reading file: {str(e)}"

def calculate(expression):
    try:
        allowed_chars = "0123456789+-*/(). "
        if not all(char in allowed_chars for char in expression):
            return "Error: Invalid characters in expression"
        return str(eval(expression))
    except Exception as e:
        return f"Error evaluating expression: {str(e)}"
```

Notice how we implemented basic safety validations in our `calculate` tool. Running raw `eval()` on unsanitized inputs generated by an AI is a massive security hazard. Never let your local tools execute arbitrary strings without strict containment.

## Step 3: Crafting the ReAct Prompt and Tool Schema

To make our LLM act as an agent, we need to instruct it on how to think, act, and interpret observations. We do this by feeding it a structured prompt that describes the available tools and mandates a strict output format.

Create a file named `agent.py`. We will start by defining our system prompt:

```python
SYSTEM_PROMPT = """You are an autonomous productivity agent.
You solve tasks step-by-step using a thought-loop of: Thought, Action, Observation.

Available tools:

1. list_directory:
   - Description: Lists files in the current working directory.
   - Parameters: Takes no arguments.
   - Usage: Action: list_directory

2. read_workspace_file:
   - Description: Reads the contents of a specific file.
   - Parameters: Takes a single string parameter (file_path).
   - Usage: Action: read_workspace_file [file_path]

3. calculate:
   - Description: Computes mathematical expressions.
   - Parameters: Takes a mathematical string expression.
   - Usage: Action: calculate [expression]

Strict Output Protocol:
Your response must follow this structure exactly at each step:

Thought: [Reason about what to do next based on previous logs]
Action: [tool_name] [parameter_if_any]

Once you have gathered all necessary information or successfully completed the user's objective, write your final answer using this format:

Final Answer: [Detailed final response for the user]

Do not combine multiple actions in a single step. Wait for the Observation after each Action."""
```

This prompt acts as the system software instructions. It forces the LLM to output its internal chain of thought before committing to a tool execution call.

## Step 4: The Core Agent Execution Loop

Now, let's implement the coordinator loop. This Python code will:
1.  Initialize our OpenAI client.
2.  Send the user goal and system prompt to GPT-4.
3.  Parse the model’s response to extract the desired `Action`.
4.  Execute the corresponding local tool function from `tools.py`.
5.  Feed the raw results (the `Observation`) back into the model context.
6.  Repeat until the model decides to output a `Final Answer`.

Append the following logic to `agent.py`:

```python
import os
import re
from openai import OpenAI
from dotenv import load_dotenv
from tools import list_directory, read_workspace_file, calculate

load_dotenv()

client = OpenAI()

def execute_local_tool(action_name, action_input):
    action_name = action_name.strip()
    action_input = action_input.strip()
    
    if action_name == "list_directory":
        return list_directory()
    elif action_name == "read_workspace_file":
        return read_workspace_file(action_input)
    elif action_name == "calculate":
        return calculate(action_input)
    else:
        return f"Error: Tool '{action_name}' is not registered."

def run_agent(user_objective):
    messages = [
        {"role": "system", "content": SYSTEM_PROMPT},
        {"role": "user", "content": user_objective}
    ]
    
    max_turns = 10
    step = 0
    
    print(f"Goal: {user_objective}\n" + "="*50)
    
    while step < max_turns:
        step += 1
        response = client.chat.completions.create(
            model="gpt-4",
            messages=messages,
            temperature=0.0
        )
        
        assistant_content = response.choices[0].message.content
        print(assistant_content)
        print("-" * 50)
        
        messages.append({"role": "assistant", "content": assistant_content})
        
        if "Final Answer:" in assistant_content:
            print("Objective successfully accomplished.")
            break
            
        action_match = re.search(r"Action:\s*(\w+)(?:\s+(.*))?", assistant_content)
        if action_match:
            tool_name = action_match.group(1)
            tool_arg = action_match.group(2) if action_match.group(2) else ""
            
            observation_result = execute_local_tool(tool_name, tool_arg)
            print(f"Observation: {observation_result}\n" + "="*50)
            
            messages.append({"role": "user", "content": f"Observation: {observation_result}"})
        else:
            print("Parser error: Could not extract tool action.")
            break
```

## Step 5: Testing our Agent

Let's see our agent in action. Create a test file named `test_file.txt` with some random numbers inside it:

```text
Project A costs: 14500
Project B costs: 22800
Project C costs: 9400
```

Now, at the bottom of your `agent.py` script, add the execution block:

```python
if __name__ == "__main__":
    objective = "Find test_file.txt, read its contents, and calculate the sum of the costs of Project A, B, and C."
    run_agent(objective)
```

Run the script from your terminal:

```bash
python agent.py
```

### The Output Trace
Watch your terminal logs closely. You will see the agent orchestrate the following sequence:

1.  **Thought**: It realizes it needs to search the workspace to see if `test_file.txt` exists.
2.  **Action**: Calls `list_directory`.
3.  **Observation**: Receives list of files, verifying `test_file.txt` is present.
4.  **Thought**: It now needs to read the contents of the file.
5.  **Action**: Calls `read_workspace_file test_file.txt`.
6.  **Observation**: Receives the project costs text.
7.  **Thought**: It extracts the numbers `14500`, `22800`, and `9400` and needs to add them.
8.  **Action**: Calls `calculate 14500 + 22800 + 9400`.
9.  **Observation**: Receives the result `46700`.
10. **Thought**: It has accomplished the goal and prepares its final output.
11. **Final Answer**: Delivers the calculated total of $46,700 to the user.

By building agents from first principles, you retain absolute control over the prompt logic, token consumption, state management, and safety parameters.
